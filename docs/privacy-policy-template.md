# Privacy Policy Template for OpenMod Bot

This is a template privacy policy for Discord servers using the OpenMod bot. Server owners should customize this template to match their specific use of the bot.

## Information We Collect

OpenMod bot collects only the minimum information necessary for proper functionality:

- **User IDs**: To track moderation actions and provide user-specific features
- **Message content**: Only when necessary for moderation (e.g., spam detection), and automatically deleted after 7 days
- **Moderation logs**: Records of warnings, mutes, kicks, and bans for administrative purposes
- **Server configuration**: Settings specific to your server's use of the bot

## Information We Do NOT Collect

- Personal information (names, emails, addresses, etc.)
- Private messages between users
- IP addresses
- Sensitive personal information

## Data Retention

- Message logs: Automatically deleted after 7 days
- Moderation logs: Retained for 180 days, then automatically deleted
- User data: Retained only as long as necessary for functionality, then automatically deleted

## Data Usage

All collected data is used solely for:
- Moderation purposes
- Server management
- Bot functionality
- Improving the bot's performance

## Data Sharing

We do not share, sell, or distribute any user data to third parties.

## User Rights

Users have the right to:
- Request deletion of their data
- Access information about what data is stored about them
- Request corrections to inaccurate data

## Security

We implement appropriate security measures to protect the data we collect.

## Contact

For questions about this privacy policy, please contact the server administrator.
